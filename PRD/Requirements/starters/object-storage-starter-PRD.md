# Object Storage Starter PRD

Author: Andy Yang

| 属性 | 内容 |
| --- | --- |
| 制品 | `microservice-framework-object-storage-starter` |
| 引入策略 | 按需显式引入 |
| 定位 | S3 兼容对象存储访问与文件治理 |

## 1. 定位与边界

Object Storage 为文件上传、下载、元数据、完整性、访问授权和生命周期提供统一能力。具体存储实现由应用在开发阶段选择，运行期不切换。

组件不建设对象存储平台，不默认提供公开 Bucket 或永久公开 URL，也不把对象存储当数据库事务资源。

## 2. 技术栈与依赖

- S3 兼容 API；具体客户端通过适配实现接入。
- 依赖 Common、JSON、Logging；Security、Database 和 Observability 可选。

## 3. 核心能力

1. 上传、下载、删除、元数据、完整性校验和对象标识。
2. 预签名 URL、临时凭据、访问范围和有效期治理。
3. 分片上传、大小/类型限制、失败清理和幂等。
4. 生命周期、过期、孤儿对象识别和清理扩展。
5. 操作日志、指标、审计事件和错误分类。

## 4. 实现要求

- 默认私有访问；预签名 URL 必须限制操作、对象、大小和有效期。
- 禁止业务直接持久化永久公开 URL；应持久化受治理对象标识。
- 上传必须校验大小、允许类型和完整性；类型校验不能只信任文件扩展名。
- 业务事务与对象上传非原子，必须提供临时对象、确认和孤儿清理流程。
- 删除、覆盖和批量操作必须显式授权，失败不得伪成功。

## 5. 配置与扩展

- `framework.object-storage.provider`
- `framework.object-storage.bucket.*`
- `framework.object-storage.presign.*`
- `framework.object-storage.upload.*`
- SPI：存储适配器、对象命名、内容校验、病毒扫描和生命周期处理。

## 6. 验收标准与方法

| 场景 | 验收方法 | 通过条件 |
| --- | --- | --- |
| 基础操作 | 上传、下载、删除真实测试对象 | 内容与元数据正确，错误分类清晰 |
| 私有访问 | 未授权直接访问对象 | 默认拒绝 |
| 预签名访问 | 测试合法、过期和越权 URL | 仅合法范围和有效期内可访问 |
| 上传治理 | 上传超大、伪造类型和损坏内容 | 请求被拒绝且临时对象清理 |
| 非原子补偿 | 模拟业务提交失败和上传中断 | 孤儿对象可识别并清理 |
| Provider 契约 | 使用两个测试适配器运行契约套件 | 公共行为一致 |

## 7. 交付物

自动配置、统一存储 API、Provider SPI、访问安全规范、生命周期与补偿规范、故障演练和验证应用。
