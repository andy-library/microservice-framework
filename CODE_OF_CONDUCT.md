# Code Of Conduct

Author: Andy Yang

Microservice Framework is built for long-term community collaboration. We expect all participants to help create a respectful, practical, and technically rigorous environment.

## Expected Behavior

- Be respectful and professional.
- Discuss technical disagreements with evidence and clear reasoning.
- Welcome contributors with different levels of experience.
- Keep issues and pull requests focused on the project.
- Avoid personal attacks, harassment, discrimination, or intentionally disruptive behavior.

## Unacceptable Behavior

- Harassment, threats, insults, or discriminatory language.
- Publishing private information without permission.
- Repeatedly derailing technical discussions.
- Submitting malicious code, credentials, or intentionally misleading reports.

## Enforcement

Project maintainers may remove comments, close issues, reject pull requests, or restrict participation when behavior harms the community or the project.

## Reporting

If you need to report a conduct issue, open a private security advisory if available, or contact the project maintainer through the repository-maintained contact channel once configured.
