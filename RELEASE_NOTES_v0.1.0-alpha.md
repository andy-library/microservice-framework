# v0.1.0-alpha - Initial Open Source Preview

Author: Andy Yang

Microservice Framework is now prepared as an initial open-source preview under the repository name `microservice-framework`.

## Highlights

- Enterprise-grade Java/Spring Boot microservice foundation.
- Parent POM, dependency BOM, framework BOM, and starter parent governance.
- 19 production-oriented Spring Boot starters.
- Standalone demo application for starter capability verification.
- JMeter scripts and bilingual performance reports.
- Apache-2.0 license.
- Community contribution, security, conduct, roadmap, issue template, pull request template, and GitHub Actions preparation.

## Verification

The open-source package has been prepared with:

- Clean repository layout.
- Sensitive local credentials removed.
- Markdown author metadata standardized as `Andy Yang`.
- Local build artifacts and raw test outputs excluded.
- Maven validation passed for parent and demo entry points.

## Notes

This is an alpha preview intended for architecture review, community feedback, starter capability verification, and continued production-readiness hardening.
